<h3 align="center">Building in public, learning out loud.</h3>

I'm a data analyst based in Indonesia who spends way too much time in Jupyter notebooks turning messy spreadsheets into something useful. Most days you'll find me wrangling data with Pandas and NumPy, writing SQL against DuckDB, or building little ETL pipelines to automate reporting that nobody asked for but everyone ends up loving. I'm slowly drifting toward data engineering because the idea of stitching together pipelines end-to-end just sounds like more fun.

#### A little about me

- 🔭 A DuckDB-powered ETL pipeline that replaces my team's Excel-based reporting.
- reading docs more than books lately
- probably overthinking a database schema right now
- keeps notes about ETL pipelines that will never be published
- happier in a terminal than in an IDE
